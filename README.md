## 构建

需要 Windows x64 和 .NET Framework 4.8。构建脚本直接调用系统自带的 .NET Framework C# 编译器，不需要安装 NuGet 包，也不会下载内核。

在本目录打开 PowerShell，运行：

```powershell
.\构建.ps1
```

输出为 `build/代理小助手.exe`。脚本在 `build` 目录已存在时会停止；再次构建前请保留需要的旧结果，再选择新的干净副本构建。不要为执行此脚本修改全局执行策略。

## 运行范围与内核版本

本仓库仅包含客户端源码及编译资源，不附带代理账号、个人配置、诊断记录、sing-box 内核或完整便携包教程。它可以编译客户端，但编译产物单独运行不能完成代理连接。

当前客户端配套的是 sing-box **1.14.3 Windows amd64**，通过独立进程调用其公开命令行接口。`src/CoreRunner.cs` 会核对 `core/sing-box.exe` 的 SHA-256：

```text
5c19bb3f8c12d4e85b3d47fe63123a7624b314b58dd7a8e32f51004f1c4d2faf
```

运行时应将编译出的 EXE 放入匹配版本的完整便携包目录，保留 `core/`、教程和第三方许可资料。不要直接换成不同版本的内核；哈希不匹配会被客户端拒绝。内核来源及下载入口见 [第三方声明](THIRD_PARTY_NOTICES.md)。
